# UI: the page

## Purpose

A local page in the browser, started with `python app.py ui`, that shows what the screener measures and what the scenario engine prices, without computing either. Every number on it comes from the screener's own code and files. Code: `screener/ui.py` (the view, standard library only) and `screener/ui_app.py` (the Dash layout and Plotly figures). Tests: `tests/test_ui.py`. Detail, acceptance criteria and evidence: [../changes/2026-11-13-ui.md](../changes/2026-11-13-ui.md), accepted 2026-11-19 and built one task at a time. Built so far: chain view steps 1 to 3, the IV surface and the variance strip, each in its own window, with the snapshot slider and the highlights linking the two.

## Interfaces

- `python app.py ui [snapshot] [--port N] [--no-browser]`.
- `ui.snapshots()`, `ui.chain_surface(name)`, `ui.chain_strip(name)` (with `source`, `foci`, `focus_by_expiry`, and each window's `left_out`), `ui.axis_ranges(names)`, `ui.run_warnings(name)`, `ui.load_snapshot(name)`; `ui_app.create_app(start)`, `ui_app.surface_figure(view, ranges, contours, camera, keys)`, `ui_app.strip_figure(strip, ranges)`, `ui_app.page_for(name, options, ranges, camera)` (returns the surface, the strip, the snapshot window, the title and the highlight data), `ui_app.focus_data`, `ui_app.highlight(data, key, held)`, `ui_app.next_focus(event, key, held)`, `ui_app.key_from(event, foci, surface_curve)`, `ui_app.respond(prop_id, value, data, held)`.
- `screener/assets/windows.js`: moves the windows; served by Dash with the page. Layout only.
- Reads through the engine's folder settings only (`scenario.CHAIN_DIR`, `IV_DIR`, `SURFACE_DIR`): `scenario.load`, `points.csv`, `run.json`, and `term.load` for the drop rule's reasons. Writes nothing.

## Gaps

- A click on the 3D surface is untested by hand: the browser pane's synthetic clicks never reach plotly.js's 3D scene, which emits a click only when a rendered frame sees the button held over a point. The page's response to the click Dash sends is tested (`test_a_click_on_the_surface_holds_its_expiry_until_let_go`); a real click is the owner's to try.
- The Host and Origin checks (AC-16) are not built yet; the page binds 127.0.0.1 only.
- The palette validator was not run (it needs Node).
