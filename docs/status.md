# Status

As of 2026-11-13

## Current state

The measuring pipeline is built and in daily use: snap, iv, surface, term, context and ledger run as `python app.py daily` at about 15:45 ET, then `response` (each strike near spot across the day's move), with the full history, prices and vrp alongside. The latest work (2026-11-01 to 11-04) made the ledger record the strike band each window was priced under, graded how resolved each window's chain was (`edge_margin`, `spans_dropped`), measured roll-down off the older curve, and refused to cache unfinished price bars. The scenario engine is built (2026-11-09, `python app.py scenario`): a position's value, Greeks and P&L under hypothetical spot, IV shifts, dates and paths, on the snapshot's own IVs, fit and term structure ([changes/2026-11-06-scenario-engine.md](changes/2026-11-06-scenario-engine.md), verified; uncommitted until the owner pushes). Since 2026-11-12 each strike keeps its IV as spot moves, and every point shows three P&Ls under umbrella IV responses to the move, with `--sessions` for the horizon ([changes/2026-11-11-iv-response.md](changes/2026-11-11-iv-response.md), verified; uncommitted). The structure chooser the README describes is not built; it will call the engine. Two paper trades are closed (Sep-25 long straddle, Oct-30 short straddle). This knowledge base was added on 2026-11-04; its open questions are in [assumptions.md](assumptions.md).
